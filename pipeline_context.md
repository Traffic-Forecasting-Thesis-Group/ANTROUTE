## Pipeline Schema Definition
**Scrapers (Twitter & News/GDELT) -> Text Pre-Cleaner -> MarianMT -> DistilBERT**

1. **Scraper**: Retrieves continuous data from X/Twitter and Local/GDELT News feeds targeting Metro Manila traffic events.
2. **Text Pre-Cleaner**: Strips URLs, `@mentions`, and arbitrary whitespaces using Regex. Preserves vital geolocation anchors and event types via NER/gazetteer matching and handles localized Tagalog traffic slang (`replace_slang`).
3. **MarianMT**: Translates Tagalog text into English (`Helsinki-NLP/opus-mt-tl-en`).
4. **Tokenizer & Embedder**: Processes translated English text through `distilbert-base-uncased` tokenizer and calculates a mean-pooled 768-dimensional DistilBERT embedding vector.

## Anomaly/Error Log
* **Rate Limits:** Hit Twitter/X API pagination limits briefly on 2026-05-15 (due to high volume of localized rain/flooding tweets); resumed with exponential backoff.
* **GDELT DOC API Throttling:** Encountered HTTP 429 (Too Many Requests) on several daily requests. The collector retried with exponential backoff (5, 10, 20 seconds where needed) and retained auditable empty payloads for days that exhausted retries, with a 3-second inter-day throttle.
* **X API Collection:** A five-minute API probe succeeded. Collection uses 2-hour output batches to limit failure scope and 5/10-second retry backoff for transient errors and HTTP 429 responses. A mocked 2-hour batch verified 24 internal 5-minute requests and one output file.
* **Translation Anomalies:** MarianMT OOV (Out-Of-Vocabulary) behavior noted for deeply localized slang terms (e.g., "buhol-buhol", "kamote rider"). Fixed via `replace_slang` dictionary intercept in `TextCleaner`.
* **Truncation/Padding Bottlenecks:** A subset of News Reports exceeded DistilBERT's 512-token max sequence limit. Enforced `max_length=512` truncation in `BatchNLPPipeline`.
