# Ten input features

The current system supports the ten requested features for modeled hourly snapshots during **June 2025–May 2026**. Estimates are allowed and labeled.

The feature-by-feature source and formula report is [estimation_methods.md](estimation_methods.md). Machine-readable provenance is in `data/processed/estimation_registry.json`, the network's provenance, `/network`, and route responses. The website displays the same basis and source references.

Historical weather uses dated provider records with an approximate city-grid assignment. Traffic, capacity, travel time, and weather speed effects are modeled. Mapped road and flood features are static temporal proxies. No complete historical traffic measurement archive is claimed.
